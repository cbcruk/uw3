# db — 원작 참조 자료

대항해시대3의 도시·발견물·도서 정리표다. 항구(`src/content/ports.ts`)와 발견물을 늘릴 때
**무엇을 넣을지 고르는 목록**으로 쓴다. 코드는 이 파일을 읽지 않는다.

| 파일              | 행  | 담긴 것                                                          |
| ----------------- | --- | ---------------------------------------------------------------- |
| `cities.csv`      | 226 | 지역 · 도시 · 위경도 · 특산물 · 시장 아이템 · 도서관 · 교회/조합 |
| `discoveries.csv` | 206 | 지역 · 발견물 · 도서관 힌트 · 도시 · 위경도 · 증거품 · 조건      |
| `books.csv`       | 127 | 도서 · 언어 · 소장 도서관 · 힌트 · 필요 기술 · 열리는 조건       |

## 옮기지 말고 고른다

`SPEC-uw3-game.md` §8.2·§11의 원칙 그대로다 — 원작 표는 **설계 참조용이지 이식용이 아니다.**

- **고르는 것:** 어느 도시를 항구로, 어느 발견물을 넣을지. 책 → 힌트 → 발견의 연결 구조
- **다시 적는 것:** 좌표 · 품목 · 값. 항구 좌표는 지금의 지명 좌표로 적는다 (SPEC-roguelike §22)
- **넣지 않는 것:** 원작의 아이템 이름(무기·장신구·증거품), 판타지 발견물(흡혈귀·네시 따위)은 넣을지 따로 정한다

## 알려진 오류

좌표는 **정수**다. 게임 격자 한 칸(0.25°)의 네 배 폭이라 발견 지점으로 쓸 수 없다.
그보다 큰 문제는 서경 부호가 빠지거나 값이 틀린 행이다. 보이는 대로 적는다 — 전수 검사는 아니다.

**이름이 맞지 않는다.** `books.csv`의 힌트 63개가 `discoveries.csv`의 도서관 힌트와 철자가 다르다
(바위돔 / 바위 돔, 성분묘교회 / 성분묘 교회, 미노타우로스 / 미노타우르스 …). 책과 발견물을 잇는 일은
이름 대조가 아니라 사람이 짝을 짓는 일이다. 제목이 빈 행이 둘 있다 — 바로 위 책의 이어지는 줄로 보인다.
