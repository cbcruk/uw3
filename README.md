# uw3

15~17세기 범선 항해 시뮬레이터와, 그 위에 얹은 격자 로그라이크.

- **시뮬레이터** — 실제 지구(Natural Earth 1:50m 해안선) 위에서 바람·해류·돛의 물리로 배를 몬다.
  기준은 "재미있는가"가 아니라 "맞는가"다. 극곡선·파일럿 차트·항해일지와 대조해 검증한다 (`SPEC.md`)
- **로그라이크** — 시뮬을 고치지 않고 위에 얹은 게임이다. 메르카토르 격자를 영역으로 나눠 층으로 삼고,
  바다는 배로, 뭍은 말·낙타로 한 칸씩 간다. 퍼머데스 런과 데일리 시드가 있다 (`SPEC-roguelike.md`)

## 시작하기

[Vite+](https://viteplus.dev/guide/)(`vp`)와 pnpm을 쓴다.

```sh
vp install
vp dev
```

기본 화면은 로그라이크다. 시뮬레이터는 주소 끝에 `#sim`을 붙여 연다.

## 조작 (로그라이크)

| 키                                  | 하는 일                                         |
| ----------------------------------- | ----------------------------------------------- |
| 방향키 · `y` `u` `b` `n` · 숫자패드 | 한 칸 이동 (대각선은 vi 키나 숫자패드)          |
| `.` · `z` · 숫자패드 5              | 기다리기                                        |
| `h` · `c`                           | 말·낙타로 하선 (선원 절반, Shift를 누르면 전원) |
| `e`                                 | 승선                                            |
| `1`–`9` · Shift+`1`–`9`             | 시장 N번째 품목 사기 · 화물 N번째 팔기 (10톤씩) |
| `r` · `f`                           | 선원 고용 · 수리                                |
| `t` · `x`                           | 조공 · 항복                                     |

## 검증

| 명령                         | 보는 것                                                    |
| ---------------------------- | ---------------------------------------------------------- |
| `vp check`                   | 포맷·린트·타입                                             |
| `vp test`                    | 코드가 맞게 도는가. 빨개지면 `src/sim/`·`src/game/`        |
| `vp run validate`            | 자료가 쓸 만한가 (근거 등급·부채). 빨개지면 `src/content/` |
| `vp run harness`             | 여러 시드로 시뮬을 돌려 수치를 낸다. 통과·실패가 없다      |
| `vp run shot`                | `scripts/shots/`의 장면대로 화면을 찍어 `.shots/`에 낸다   |
| `vp run verify -- 기록.json` | 데일리 기록을 다시 돌려 받을지 가린다                      |

## 구조

| 경로           | 담긴 것                                                        |
| -------------- | -------------------------------------------------------------- |
| `src/sim/`     | 시뮬레이터 — 지리·달력·바람·해류·배·안개·난수                  |
| `src/game/`    | 로그라이크 레이어. `src/sim/`을 import만 한다                  |
| `src/content/` | 항구·배·항로·튜닝 표. 수치마다 근거 등급이 달린다              |
| `src/ui/`      | 지구본(시뮬)과 격자 화면(게임)                                 |
| `src/harness/` | 헤드리스 충실도 측정                                           |
| `scripts/`     | 검증·측정·스크린샷·기록 검증 스크립트                          |
| `db/`          | 대항해시대3 도시·발견물·도서 표. 고르는 목록이지 옮기지 않는다 |
